## 🚀 How to Run (Troubleshooting)
Because these apps use the microphone, **browser security is strict**.

### Option A: Use the Live Links (Recommended)
Click the links at the top of this ReadMe (once deployed via GitHub Pages).

### Option B: Run Locally
Do not simply double-click the HTML files. The microphone will be blocked.
1.  **Python:** Run `python -m http.server` in the folder and visit `http://localhost:8000`.
2.  **VS Code:** Install the "Live Server" extension and click "Go Live".
